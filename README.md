How to Run the Project (Simple Steps)
1. Install Requirements

Install Node.js (LTS) → https://nodejs.org

Install pnpm:

npm install -g pnpm

2. Open the Project

Unzip the project

Open the folder in VS Code

Open Terminal in VS Code

3. Install Dependencies
pnpm install

4. Run the Project
pnpm dev

5. Open in Browser

Go to:

http://localhost:3000

Common Fix

If it doesn’t work:

pnpm install
pnpm dev
